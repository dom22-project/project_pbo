### 4. ⚙️ SCRIPT OTOMATIS

#### `optimize_xampp.bat` ⭐ JALANKAN INI
- **Bahasa**: Batch script untuk Windows
- **Fungsi**: Otomatis update php.ini dan my.ini
- **Cara pakai**:
  ```
  1. Klik kanan
  2. Run as administrator
  3. Tunggu sampai selesai
  4. Restart XAMPP
  ```
- **Hasil**: Automatic backup file created (php.ini.backup, my.ini.backup)
