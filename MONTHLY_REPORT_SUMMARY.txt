📊 STATISTIK YANG DITAMPILKAN
=============================
┌──────────────────────────────────────────────────────────┐
│ DASHBOARD STATISTIK                                      │
├──────────────────────────────────────────────────────────┤
│ Total Operasi      → Jumlah operasi dalam bulan         │
│ Total Pendapatan   → Sum(total) semua operasi           │
│ Dokter Unik        → COUNT(DISTINCT dokter)            │

📑 TABEL DETAIL
===============

===============

   - Nama file: laporan_[BULAN]_[TAHUN].csv
   - Click: "Export CSV" button

2. EXPORT PDF

   - Pilih printer: "Save as PDF"
   - Click: Save
   - Layout otomatis adjust untuk print

🐛 TROUBLESHOOTING
==================

Q: Data tidak muncul di laporan?
A: Pastikan:
   - Data sudah di-input
   - Punya tanggal yang valid
   - Is_latest = 1 (data terbaru)

Q: Dropdown bulan kosong?
A: Belum ada data operasi. Input beberapa data dulu.

Q: Export tidak work?
A: Clear cache browser atau coba browser lain.

Q: Styling tidak benar?
A: Clear cache (Ctrl+Shift+Del) atau hard refresh (Ctrl+Shift+R).

📊 SQL QUERIES (BEHIND THE SCENES)
==================================

Query 1: Get monthly data
├─ SELECT * FROM database
├─ WHERE YEAR(tanggal) = @year
├─ AND MONTH(tanggal) = @month
├─ AND is_latest = 1
└─ ORDER BY tanggal DESC

Query 2: Get available months
├─ SELECT YEAR(tanggal), MONTH(tanggal), COUNT(DISTINCT id)
├─ FROM database
├─ WHERE tanggal IS NOT NULL AND is_latest = 1
├─ GROUP BY YEAR(tanggal), MONTH(tanggal)
└─ ORDER BY YEAR DESC, MONTH DESC
