# 📊 MONTHLY REPORT FEATURE - README

> Dashboard Laporan Bulanan untuk Aplikasi PBO

## 🚀 Quick Start

### Akses Fitur
1. Login ke aplikasi PBO
2. Klik **"Laporan Bulanan"** di menu navbar
3. Dashboard akan membuka secara otomatis

### Lihat Data
1. Dashboard otomatis menampilkan bulan sekarang
2. Gunakan dropdown untuk ganti bulan
3. Lihat statistik dan tabel operasi

### Export Data
- **CSV**: Klik "Export CSV" untuk unduh ke Excel
- **PDF**: Klik "Cetak" untuk print/save as PDF

- 📊 Statistik ringkasan (Total, Revenue, Dokter, Asuransi)

- 💾 Export CSV untuk Excel
