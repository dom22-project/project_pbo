## 🚀 CARA MENGGUNAKAN

### Akses Fitur
1. Login ke aplikasi
2. Klik **"Laporan Bulanan"** di menu navbar
3. Dashboard otomatis menampilkan bulan sekarang

### Lihat Data
1. Pilih bulan dari dropdown (optional)
2. Klik "Tampilkan Data"
3. Lihat statistik dan tabel

### Export Data
- **CSV**: Klik "Export CSV" untuk unduh ke Excel
- **PDF**: Klik "Cetak" untuk print/save as PDF
